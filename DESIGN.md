# Existing visual system

The census uses a light reading surface, Overused Grotesk body and headings, and IBM Plex Mono for metadata. Shared navigation comes from views/nav1001.js. Content uses a 1180px maximum width, 20px outer gutters, hairline dividers and restrained orange/blue accents. Research should reuse these fonts, header and locale helpers, with narrower article prose, responsive headings and a directly labeled comparison chart. Keep source limitations close to the figures.
